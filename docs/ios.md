# iOS export + QA (issue #9)

Packaging only — no gameplay fork. Same Godot 4 project/branch as every
other target; the only iOS-specific files are the export preset, the
exported 1024px icon source, and this note.

## What was added

- `export_presets.cfg` — two presets, both platform `iOS`, bundle ID
  `org.permaculture.terrain`, min iOS **15.0**, iPhone + iPad, arm64:
  - **`iOS`** → `build/ios/permaculture.ipa` (shippable artifact; needs
    signing filled in at release time, see below).
  - **`iOS (Xcode Project)`** → `build/ios/permaculture.xcodeproj`
    (`application/export_project_only=true`). Unsigned simulator QA path.
- `icons/icon_1024.png` — opaque 1024×1024 icon rasterized from
  `res://icon.svg` (SVG has rounded corners; composited onto its own base
  fill `#C9A86A` because the App Store icon must be opaque). Generated by
  `tools/gen_ios_icon.gd`, referenced as `icons/icon_1024x1024`; the
  exporter derives all other sizes (180/167/152/120/87/…) automatically.
  Verified in the exported `Images.xcassets/AppIcon.appiconset`.
- `project.godot` (shared, packaging-only settings):
  - `rendering/renderer/rendering_method.mobile="mobile"` (desktop stays
    `forward_plus`; iOS uses the `.mobile` override).
  - `rendering/textures/vram_compression/import_etc2_astc=true` (required
    for a valid iOS export configuration).
  - `display/window/handheld/orientation=4` (sensor landscape; the terrain
    view is landscape-first).

No GDScript gameplay changes. `godot --headless --path . --script
res://tests/test_terrain.gd` still passes (34 checks).

## Signing (release only)

The committed preset uses `application/app_store_team_id="XXXXXXXXXX"`
placeholder and empty signing identities/profiles. Signed builds fill
these in per-machine or per-CI-job (team IDs and profiles are
environment secrets, not repo content). Anything unsigned below uses
`CODE_SIGNING_ALLOWED=NO`, which is simulator-only.

## QA procedure (unsigned simulator)

```sh
godot --headless --path . --export-release "iOS (Xcode Project)" \
  build/ios/permaculture.xcodeproj
# NOTE: Godot 4.7.2's official ios.zip simulator slice
# (libgodot.ios.*.xcframework/ios-arm64_x86_64-simulator/libgodot.a) is
# x86_64-only despite the folder name, so Apple-Silicon simulator builds
# must target x86_64 (runs translated under Rosetta 2):
xcodebuild -project build/ios/permaculture.xcodeproj \
  -target permaculture -configuration Release -sdk iphonesimulator \
  -arch x86_64 ONLY_ACTIVE_ARCH=NO build \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO
SIMCTL=${SIMCTL:-xcrun simctl}
$SIMCTL install booted \
  build/ios/build/Release-iphonesimulator/permaculture.app
$SIMCTL launch booted org.permaculture.terrain
$SIMCTL io booted screenshot docs/evidence/9/still.png
$SIMCTL io booted recordVideo docs/evidence/9/demo.mp4
# ...let it record, then Ctrl-C to finalize the file.
```

Environment note (2026-10-26, macOS 26.6.2, Xcode 27.1): the
`xcrun`/`usr/bin/simctl` wrapper hangs because it runs
`xcodebuild -runFirstLaunch` when `/Library/.../CoreSimulator.framework`
(1171.7) is older than Xcode's expected 1174.9.2. In that situation
override the default, e.g.
`SIMCTL=/Library/Developer/PrivateFrameworks/CoreSimulator.framework/Versions/A/Resources/bin/simctl`,
which calls the real `simctl` inside the framework directly.

## QA results

- Export (Xcode project): OK — `permaculture.xcodeproj`, `permaculture.pck`,
  `permaculture.xcframework`, icons, `permaculture-Info.plist` (bundle ID
  via `PRODUCT_BUNDLE_IDENTIFIER`, landscape orientations, launch
  storyboard) all generated with no config errors.
- Simulator build (Release, iphonesimulator SDK, `-arch x86_64` because
  the 4.7.2 template's simulator slice is x86_64-only, signing disabled):
  OK — `** BUILD SUCCEEDED **`.
- Install + launch on booted iPhone SE (3rd gen), iOS 18.5: OK, app stays
  alive in foreground (verified via `launchctl list`).
- Terrain renders in-app identically to desktop evidence
  (`docs/evidence/2/terrain_topdown.png`): same camera framing, same
  vertex-color landforms. First frame takes ~60 s wall-clock (Rosetta
  translation + shader compile on first launch); steady after that.
- Orbit/place: the terrain MVP (#2) has no touch orbit/place controls yet
  (explicitly deferred to hex-overlay/HUD issues) — nothing to exercise.
  QA covers launch, render, and stability only.
- Evidence: `docs/evidence/9/demo.mp4` (13.5 s, HEVC, `simctl io
  recordVideo`; stream is 750×1334 with a rotate-90 display matrix so it
  plays as 1334×750 landscape) + `still.png` (1334×750 `simctl io
  screenshot`).
